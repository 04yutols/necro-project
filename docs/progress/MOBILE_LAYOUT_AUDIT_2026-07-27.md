# スマホレイアウト監査・修正概要（2026-07-27）

## 目的

スマホ操作を主対象として、主要画面のレイアウト崩れ、文字の見切れ、縦スクロール不能、タップ領域不足を確認し、再発防止を含めて修正する。

## 監査条件

- 基準表示領域: `390 x 844 CSS px`（一般的なスマホ縦持ち）
- 補助表示領域: `375 x 667 CSS px`（小型スマホ縦持ち）
- データ条件: `devPreset=endgame`（全ナビ・装備・残滓・黄泉を表示可能な状態）
- 対象: 拠点、ワールドマップ、転職、編成、統合詳細ハブ、武器庫、ネクロラボ、黄泉、ログ、戦闘導線
- 確認方法: 実ブラウザ巡回、DOM実寸計測、横方向オーバーフロー／非スクロール領域の検査、既存Playwrightシナリオ確認

## 非不具合として扱う項目

- 転職画面の横方向ジョブレールは、意図した横スクロール領域のためページ横溢れには含めない。
- MAPの装飾SVG／パーティクルが画面外へ描画される箇所は、操作DOMと文書幅を増加させないため対象外とする。
- 一行省略自体は、別の識別情報が残り、フル名称をアクセシブル名で取得できる場合のみ許容する。

## 完了条件

1. 390px幅で文書全体の意図しない横スクロールが発生しない。
2. 拠点、MAP、転職、編成、統合詳細、武器庫、研究所、黄泉、ログで主要情報が判別可能である。
3. 主要な戻る・タブ・決定・再挑戦・下部ナビのタップ領域が44px以上である。
4. 武器庫と縦一覧がスマホでスクロール可能である。
5. TypeScript、Jest、Playwrightの関連テストが成功する。

## 実施結果

- MOB-01〜MOB-10を修正済み。
- `390 x 844` と `375 x 667` の両方で、対象画面の文書横溢れ、意図しない横方向の文字クリップ、安定表示後44px未満の操作ボタンが0件。
- 統合詳細ハブでは残滓を部位＋短縮名で判別でき、武器庫ではレア度・WEAPON ATK・サブオプションを維持したまま縦スクロール可能。
- 戦闘HUDのAUTO、速度切替、撤退を44px以上へ統一。
- 検証結果: `npx tsc --noEmit` 成功、E2E用TypeScript成功、Jest 92スイート／815件成功、関連Playwright 13件成功、production build成功。
