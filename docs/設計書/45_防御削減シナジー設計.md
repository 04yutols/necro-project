# 45. 防御削減シナジー（defenseReducePct）設計

> 作成日: 2026-05-24  
> 対象バグ: TECH_DEBT NM-5  
> 担当ファイル: `src/logic/BattleDamage.ts`

---

## 1. 問題の概要

### 実装前の状態

`TribeSynergySystem.ts` は ORC 種族シナジーに応じて `SynergyBonus.defenseReducePct` を計算する。  
しかし `calculateBattleDamage()` は `synergyBonus` を受け取りながら `defenseReducePct` を DEF 計算に使っていない。

```
現状:
  effectiveDef = max(0, defenderStats.def)   ← defenseReducePct を無視
  defMult      = 1 - effectiveDef / (effectiveDef + 200)
```

ORC パーティを組んでも防御削減ボーナスがダメージに反映されず、  
**「鬼の厚皮」シナジーが ORC にとって無意味なステータス**になっている。

---

## 2. defenseReducePct が付与されるシナジー

| 条件 | 効果 |
|---|---|
| ORC × 2（Partial） | `defenseReducePct +15` |
| ORC × 3（Full） | `defenseReducePct +25` |
| ORC + UNDEAD クロス共鳴 | `defenseReducePct +10` |

**最大スタック例:**  
ORC × 3（Full） + ORC × UNDEAD クロス = **+35%**

---

## 3. 修正後のダメージ計算式

```
effectiveDef = max(0, DEF × (1 - clamp(defenseReducePct, 0, 100) / 100))
defMult      = 1 - effectiveDef / (effectiveDef + 200)
```

- `defenseReducePct` は **割合軽減**（乗算）。加算ではない。
- `clamp(0, 100)` でオーバーフロー防止（100% 超は DEF = 0 扱い）。
- 0% の場合は既存挙動と完全同一。

### 数値例（ATK=100, power=1.0, DEF=100）

| defenseReducePct | effectiveDef | defMult | damage |
|---|---|---|---|
| 0%（なし） | 100 | 0.6667 | 66 |
| 15%（ORC×2） | 85 | 0.7018 | 70 |
| 25%（ORC×3） | 75 | 0.7273 | 72 |
| 35%（ORC×3+UNDEAD） | 65 | 0.7547 | 75 |
| 100%（理論最大） | 0 | 1.0000 | 100 |

## 5. 実装仕様

```typescript
// Before
const defenderDef = Math.max(0, defenderStats.def);
const defMult = 1 - defenderDef / (defenderDef + 200);

// After
const rawDef = Math.max(0, defenderStats.def);
const reducePct = Math.min(100, Math.max(0, synergyBonus.defenseReducePct ?? 0));
const defenderDef = rawDef * (1 - reducePct / 100);
const defMult = 1 - defenderDef / (defenderDef + 200);
```

**注意点:**
- `defenderDef` が 0 になっても `defMult = 1 - 0/200 = 1.0` で除算エラーにはならない
- 他のボーナス（属性/会心/耐性）の適用順は変わらない
