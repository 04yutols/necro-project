# 44. 職業別ステータス成長率設計

## 目的

ステージクリア時のレベルアップで増加する基礎ステータスを、全職業一律ではなく、現在育成している職業の個性に応じて変化させる。

これにより、転職システムの「どの職業でレベルを上げたかが最終的な強さに積み上がる」という設計を、パッシブボーナスだけでなく基礎成長にも反映する。

## 現状の問題

従来は `processStageResultForUser()` 内で以下の固定値を使っていた。

```text
Lv +1 ごとに HP +40 / ATK +6 / DEF +4
```

そのため、剣士で育てても魔法使いで育てても、DB に保存される `Character.hp / atk / def` の伸びが同じだった。

## 設計方針

### 成長の対象

第1段階では、既存 DB の基礎成長対象である以下3ステータスに限定する。

- HP
- ATK
- DEF

SPD・会心系・効果命中/抵抗は、現時点では `statModifiers` / `levelBonuses` / 装備・残滓で差別化する。  
SPD を基礎成長に含めるとターン順・行動回数の影響が大きいため、別バランス調整として扱う。

### 成長式

`jobs.json` に `growthModifiers` を追加し、基礎成長量へ倍率を掛ける。

```text
baseGrowth = { hp: 40, atk: 6, def: 4 }
growth[stat] = round(baseGrowth[stat] * job.growthModifiers[stat] * levelsGained)
```

倍率が未定義・0以下・非数値の場合は `1.0` として扱う。

### `statModifiers` との役割分担

| 項目 | 役割 | 適用タイミング |
|---|---|---|
| `growthModifiers` | その職業でレベルを上げた時の永続的な基礎成長 | ステージクリア後のレベルアップ時 |
| `statModifiers` | 現在選択中の職業による一時的なステータス補正 | `calculateJobAdjustedStats()` 実行時 |
| `levelBonuses` | マイルストーン到達時の永続パッシブ | `JobService.onLevelUp()` |

例: ベルセルクでレベルを上げると基礎 ATK が大きく伸びる。  
その後に魔剣士へ転職しても、その高い基礎 ATK に魔剣士の `statModifiers` が掛かる。

## 職業別成長倍率

| 職業 | HP | ATK | DEF | 方向性 |
|---|---:|---:|---:|---|
| 剣士 | 1.20 | 1.15 | 1.20 | 前衛の安定成長 |
| 魔法使い | 0.75 | 1.10 | 0.75 | 脆いが攻撃成長は確保 |
| 闇術師 | 1.00 | 0.85 | 1.05 | 継戦・弱体寄り |
| 盗賊 | 0.85 | 1.10 | 0.80 | 軽量アタッカー |
| 魔剣士 | 1.15 | 1.10 | 1.30 | 防御寄りの二次前衛 |
| ベルセルク | 1.00 | 1.45 | 0.75 | ATK特化 |
| アークメイジ | 0.70 | 1.25 | 0.65 | 魔法火力特化 |
| ソーサラー | 0.80 | 1.20 | 0.70 | 高速魔法寄り |
| ウォーロック | 0.85 | 1.15 | 0.85 | 闇火力と弱体 |
| ネクロマンサー | 0.95 | 1.20 | 0.95 | 死霊術と単体火力 |
| アサシン | 0.75 | 1.35 | 0.70 | 処刑火力特化 |
| トリックスター | 0.85 | 1.25 | 0.80 | 攻撃寄り万能型 |

## データフロー

```text
Stage clear
  -> processStageResultForUser()
  -> current UserJob の exp / level 更新
  -> levelsGained を算出
  -> MasterDataService.getJob(currentJobId)
  -> calculateJobGrowthIncrements(job, levelsGained)
  -> Character.hp / atk / def を increment
  -> loadCharacterForUser()
  -> calculateJobAdjustedStats(baseStats, currentJob)
```

旧 `GameManager.processStageResult()` 経路も同じ `calculateJobGrowthIncrements()` を参照する。

## 実装ファイル

- `src/types/game.ts`
  - `JobGrowthModifiers` と `JobData.growthModifiers` を追加。
- `src/data/master/jobs.json`
  - 全12職へ `growthModifiers` を追加。
- `src/logic/JobGrowthSystem.ts`
  - 基礎成長量、倍率正規化、増分計算を共通化。
- `src/app/actions.ts`
  - ステージクリア後のレベルアップ処理で職業別成長を適用。
- `src/logic/GameManager.ts`
  - 旧サーバー経路でも同じ成長計算を適用。

## テスト方針

- `growthModifiers` がない場合、従来の一律成長と同じ結果になる。
- 職業別倍率で HP/ATK/DEF の増分が変わる。
- 全職業に `growthModifiers` が定義されている。
- 新規アカウントから 1-1 クリアまでの統合テストで、剣士の成長倍率が DB の `baseStats` に反映される。
