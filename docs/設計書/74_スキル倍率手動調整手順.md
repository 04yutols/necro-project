# 74 — スキル倍率 手動調整手順

> 対象: `src/data/master/skills.json` / `src/data/master/jobs.json` / `scripts/skill-report.mjs`  
> 作成日: 2026-05-30  
> 関連: `19_スキルバランス設計書.md` / `IMP-4` / `IMP-5`

---

## 1. 目的

スキルは職業の個性とバトルテンポを決める。`power` / `mpCost` / `targetType` / `attackType` / 状態異常率が設計書19の範囲から外れると、通常攻撃より弱いスキルや、AoEだけが過剰に強い状態が生まれる。ここでは、スキルを直接編集しやすくするための確認手順とレポートを定義する。

---

## 2. 編集するファイル

### 2.1 スキル本体

`src/data/master/skills.json`

```json
"skill_warrior_wind_slash": {
  "id": "skill_warrior_wind_slash",
  "name": "鎌鼬",
  "mpCost": 4,
  "power": 1.25,
  "type": "PHYSICAL",
  "element": "WIND",
  "attackType": "SLASH",
  "targetType": "ALL_ENEMIES",
  "effectKey": "wind_slash"
}
```

### 2.2 職業との紐付け

`src/data/master/jobs.json`

```json
"skills": [
  { "level": 1, "skillId": "skill_warrior_1" },
  { "level": 8, "skillId": "skill_warrior_wind_slash" }
]
```

レポートは `jobs.json` の参照から Tier 1 / Tier 2 を推定する。未参照スキルは WARN になる。

---

## 3. レポートスクリプト

### 3.1 警告があるスキルだけ表示

```bash
npm run balance:skills
```

### 3.2 全スキルを表示

```bash
npm run balance:skills -- --all
```

### 3.3 特定スキルだけ確認

```bash
npm run balance:skills -- --skill=skill_darkpriest_1 --all
```

### 3.4 CI向け

```bash
npm run balance:skills -- --strict
```

`FAIL` がある場合に exit code `2` で終了する。

---

## 4. レポート指標

| 指標 | 意味 |
|---|---|
| `cost` | `mpCost`。現行では Energy 消費量として扱う |
| `power` | ダメージ倍率 |
| `tier` | 参照元職業の最大Tier |
| `band` | low / mid / high のコスト帯 |
| `range` | 設計書19に基づく推奨 power 範囲 |

状態異常スキルは、`power` が少し低くても許容する。ただし、説明文に「吸収」「回復」があるのに `healSelfPct` や `HP_DRAIN` 系フラグがない場合は、実装未接続の疑いとして WARN にする。

既存スキルには演出・職業個性を優先した軽微な上下振れがあるため、レポートでは推奨範囲から約10%以内のズレは警告しない。

---

## 5. 調整手順

1. `npm run balance:skills -- --all` を実行する。
2. `FAIL` がある場合は、`type` / `targetType` / `attackType` / `element` / `effectKey` の欠落を先に直す。
3. `power` が範囲外の場合は、スキルの役割を確認する。
4. AoE は単体より低倍率にする。全体命中の合計ダメージで見る。
5. 状態異常付きは `ailmentBaseRate` と `power` の合計価値が高すぎないようにする。
6. 説明文と実装フラグがズレている場合は、文言を直すかスキル効果を実装する。
7. `jobs.json` に新スキルを追加した場合、解放レベルが既存スキルと近すぎないか確認する。

---

## 6. 現状の代表例

`skill_darkpriest_1` は説明文が「生命力を吸収」「HPを回復」だが、現状のスキルデータには `healSelfPct` などの自己回復定義がない。これは `IMP-4` の実装修正候補であり、数値だけでなく BattleEngine / BattleCanvas への接続が必要になる。

---

## 7. 推奨確認コマンド

```bash
npm run balance:skills -- --skill=skill_darkpriest_1 --all
npm test -- --runInBand src/logic/BattleEngine.test.ts
```

スキルデータのみの調整ならレポート確認で十分だが、効果フィールドを増やした場合は BattleEngine テストも更新する。
