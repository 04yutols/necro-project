# 47. SP 初期値・レベル成長設計

> 作成日: 2026-05-24  
> 対象問題: バトル開始時 SP=0 のためスキルを初手から使えない / maxEnergy がレベルで伸びない
> 担当ファイル: `src/data/master/jobs.json`, `src/app/actions.ts`, `src/logic/BattleEngine.ts`

---

## 1. 問題の概要

### 現状のコード

```typescript
// src/app/actions.ts（キャラ生成時）
currentEnergy: 0,                                   // ← 固定 0
maxEnergy: currentJob.energyCurve?.baseMaxEnergy ?? 100, // ← レベル無視
```

```typescript
// src/logic/BattleEngine.ts（通常攻撃 SP 回収）
let energyGain = 20;   // ← jobs.json の energyRegen を無視して固定 20
```

### 症状

| 問題 | 影響 |
|---|---|
| 戦闘開始 SP = 0 | スキルコスト 4 でも使えない（初手は通常攻撃しか選べない） |
| maxEnergy がレベル固定 | Lv99 でも Lv1 と同じ SP 上限（成長感ゼロ） |
| energyRegen 未接続 | jobs.json の値が実際のリジェネに反映されない |

---

## 2. 設計方針

王道 JRPG スタイルで **「序盤からスキルが選べる、でも大技は溜めが必要」** を実現する。

### 体感目標

| 場面 | 目標 |
|---|---|
| バトル開始直後 | 基本スキル 1 回は即使える（残 SP でもう 1 回選択肢あり） |
| 通常攻撃 1〜2 回後 | 中コストスキルが使えるようになる |
| 通常攻撃 3 回後（Lv1） | アルティメット（魔神化奥義）発動ライン到達 |
| 高レベル | アルティメットラインに早く到達できる（成長の恩恵） |

## 3. 変更内容

### 3-1. `energyCurve` に新フィールドを追加（`src/data/master/jobs.json`）

各職業の `energyCurve` オブジェクトに 2 フィールドを追加する。

```typescript
// 既存
energyCurve: {
  baseMaxEnergy: number,   // Lv1 時の maxEnergy（変更なし）
  energyRegen: number,     // 通常攻撃 1 回あたりの SP 回収量（既存・今後 BattleEngine に接続）
  ultimateCost: number,    // アルティメット発動コスト（変更なし）
}

// 追加する 2 フィールド
  initialSpPct: number,    // バトル開始時 SP = floor(maxEnergy × initialSpPct / 100)
  spGrowthPerLevel: number // レベルアップごとに maxEnergy に加算される値
```

### 3-2. maxEnergy の計算式（`src/app/actions.ts`）

```typescript
// Before
maxEnergy: currentJob.energyCurve?.baseMaxEnergy ?? 100,

// After
const level = character.jobs.find(job => job.jobId === currentJobId)?.level ?? 1;
const energyCurve = currentJob.energyCurve;
const maxEnergy = (energyCurve?.baseMaxEnergy ?? 100)
  + (energyCurve?.spGrowthPerLevel ?? 0) * (level - 1);
```

`maxEnergy` はキャラクターデータの `maxEnergy` フィールドに保存する。

---

### 3-3. バトル開始時の initialEnergy（`src/app/actions.ts`）

```typescript
// Before
currentEnergy: 0,

// After
const initialEnergy = Math.floor(
  maxEnergy * ((currentJob.energyCurve?.initialSpPct ?? 40) / 100)
);
// ...
currentEnergy: initialEnergy,
```

---

### 3-4. BattleEngine 内の固定 energyGain を energyRegen に接続（`src/logic/BattleEngine.ts`）

```typescript
// Before（通常攻撃時）
let energyGain = 20;

// After
const jobEnergyRegen = this.state.player.energyCurve?.energyRegen ?? 20;
let energyGain = jobEnergyRegen;
```

> スキル使用時は `energyGain = skillData.isUltimate ? 0 : 15;`  
> 通常攻撃時のみ `energyRegen` を使う。スキル回収は引き続き固定 15。

`player` オブジェクトに `energyCurve` を保持させるか、`jobId` から参照するよう接続する。

## 4. 数値シミュレーション（Lv1〜99 の主要職業）

`初期SP` = `floor(maxEnergy × initialSpPct / 100)`  
`ultimateCost` = `baseMaxEnergy`（固定。高レベルほど早く到達できる）

| 職業 | Lv1 maxSP / 初期SP | Lv20 maxSP / 初期SP | Lv50 maxSP / 初期SP | Lv99 maxSP / 初期SP |
|---|---|---|---|---|
| warrior | 100 / **40** | 119 / 47 | 149 / 59 | 198 / 79 |
| mage | 80 / **48** | 118 / 70 | 178 / 106 | 276 / **165** |
| dark_knight | 110 / **33** | 129 / 38 | 159 / 47 | 208 / 62 |
| berserker | 120 / **60** | 158 / 79 | 218 / 109 | 316 / **158** |
| archmage | 100 / **65** | 157 / 102 | 247 / 160 | 394 / **256** |
| necromancer | 120 / **60** | 158 / 79 | 218 / 109 | 316 / 158 |

### 戦士 Lv1 での通常攻撃後の SP 推移

| ターン | 行動 | SP |
|---|---|---|
| 開始時 | — | **40**（基本スキル 1 回使える） |
| T1 通常攻撃 | +20 | 60（中コストスキル圏） |
| T2 通常攻撃 | +20 | 80（高コストスキル圏） |
| T3 通常攻撃 | +20 | 100（アルティメット到達） |

### アルティメット（ultimateCost = baseMaxEnergy）到達ターン数

| 職業 | Lv1 初期SP | 不足SP | 攻撃回数 |
|---|---|---|---|
| warrior | 40 | 60 | **3 回** |
| mage | 48 | 32 | **3 回（regen=15）** |
| dark_knight | 33 | 77 | **4 回** |
| berserker | 60 | 60 | **3 回（regen=25）** |

## 7. 変更しないもの

- `ultimateCost` — 固定値のまま。高レベルになるほど早く到達できる自然な成長を保つ
- スキルの `mpCost` 値 — 別途スキルバランス調整が必要な場合は個別設計書で扱う
- スキル使用時の固定 SP 回収（+15）— 通常攻撃リジェネとは分離して管理
