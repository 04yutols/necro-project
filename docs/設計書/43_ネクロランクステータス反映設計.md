# 43. ネクロレベル／ランクのステータス反映設計

## 目的

`Character.necroBaseStatsBonus` / `NecroStatus.baseStatsBonus` を、戦闘ダメージ計算とキャラクターステータス表示の両方へ接続する。

これにより、ネクロランク上昇が単なる編成コスト増加ではなく、主人公の基礎戦闘力の成長として体感できるようにする。

## 現状の問題

- DB には `Character.necroBaseStatsBonus` が保存されている。
- `NecroService.performRankUp()` ではランクアップ時に `+0.5` される。
- しかし `CharacterData` に補正値が載っていないため、`calculateCharacterStatProfile()` へ届かない。
- その結果、装備画面・編成画面・バトル計算がネクロランクを参照できない。

## 反映方針

### 対象ステータス

ネクロランク補正は、職業補正後の基礎ステータスに対して適用する。

対象は以下の4項目に限定する。

- HP
- ATK
- DEF
- SPD

会心率・会心ダメージ・効果命中・効果抵抗は、装備や残滓で個性を作る特殊値として扱うため、ネクロランク倍率では増やさない。

### 計算順

`calculateCharacterStatProfile()` の計算順を以下に統一する。

```text
職業適用後ステータス
  + ネクロランク増分
  + 職業パッシブ
  + 武器
  + 深淵の残滓
  = 最終ステータス
```

`%` オプションの参照元は、ネクロランク補正後の基礎値とする。

```text
rankedBase = jobStats + necroBonus
residueAtkPercent = rankedBase.atk * ATK% / 100
```

### ネクロ補正式

`baseStatsBonus` は倍率として扱う。

```text
necroBonus[stat] = jobStats[stat] * (baseStatsBonus - 1)
```

例:

```text
jobStats.atk = 100
baseStatsBonus = 1.5
necroBonus.atk = 100 * (1.5 - 1) = 50
rankedBase.atk = 150
```

`baseStatsBonus` が未設定・0以下・非数値の場合は `1.0` として扱い、既存セーブやモック環境では補正なしになる。

## データフロー

```text
Prisma Character.necroBaseStatsBonus
  -> toServerGameData()
  -> ServerGameData.player.necroBaseStatsBonus
  -> Zustand loadFromServer()
  -> CharacterData.necroBaseStatsBonus
  -> calculateCharacterStatProfile()
  -> 装備UI / 編成UI / BattleEngine
```

`NecroStatus.baseStatsBonus` はネクロ画面やコスト管理用の正規状態として保持し、`CharacterData.necroBaseStatsBonus` は計算用スナップショットとして扱う。

`setNecroStatus()` が呼ばれた場合は、Zustand 内の `player.necroBaseStatsBonus` も同時に更新する。

## UI/UX反映

既存 UI は `calculateCharacterStatProfile()` の `total` を参照しているため、以下に自動反映される。

- 装備画面のステータス表示
- LegionHub の主人公ステータス
- BattleCanvas のプレイヤーステータスとダメージ計算

`BattleEngine` では、主人公が与えるダメージだけでなく、モンスター全滅後に主人公が直接受けるダメージの DEF 参照も `calculateCharacterStatProfile().total.def` に統一する。

また、`StatBreakdown.necro` を追加し、将来 UI 側で「ネクロランク補正」の内訳表示を作れるようにした。

## 実装ファイル

- `src/types/game.ts`
  - `CharacterData.necroBaseStatsBonus?: number` を追加。
- `src/app/actions.ts`
  - `toServerGameData()` で DB の `necroBaseStatsBonus` を `player` に載せる。
- `src/store/useGameStore.ts`
  - `loadFromServer()` / `setNecroStatus()` で `player.necroBaseStatsBonus` を同期。
- `src/logic/StatSystem.ts`
  - `calculateNecroBaseStatsContribution()` を追加。
  - `calculateCharacterStatProfile()` に `necro` 内訳と倍率反映を追加。
- `src/logic/GameManager.ts`
  - server-side の `CharacterData` 変換にも `necroBaseStatsBonus` を追加。
- `src/logic/BattleEngine.ts`
  - 主人公への直接被弾時、最終 DEF を参照して被ダメージを計算。

## テスト方針

- 既存の `baseStatsBonus` 未設定ケースは、補正なしで既存値を維持する。
- `baseStatsBonus = 1.5` の場合、HP/ATK/DEF/SPD のみ増加することを検証する。
- `%` 残滓がネクロ補正後の基礎値を参照することを検証する。
- 不正な倍率は `1.0` へ正規化することを検証する。
- `BattleEngine` で与ダメージが上がり、直接被弾ダメージが下がることを検証する。
