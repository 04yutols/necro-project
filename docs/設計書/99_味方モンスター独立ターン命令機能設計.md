# 99. 味方モンスター独立ターン命令機能設計

> 作成日: 2026-06-07  
> 対象: BattleEngine、TurnOrderSystem、BattleCanvas、戦闘UI

## 背景

現状の味方モンスターは、主人公が攻撃した後に自動追撃するだけで、独立した手番を持たない。
これでは使役モンスターを「編成して命令する」体験にならず、ネクロマンスで仲間を増やす価値も弱い。

味方モンスターにも行動値(AV)によるターンを作り、その手番でプレイヤーが攻撃命令を出せるようにする。

## 目的

1. 味方モンスターを主人公・敵と同じターン順序プレビューに表示する。
2. 味方モンスターが手番を迎えたら、専用の命令UIを表示する。
3. 味方モンスターの攻撃は主人公の攻撃後追撃ではなく、味方モンスター自身のターンでのみ発生する。
4. 味方モンスターの攻撃には既存の `MonsterAttackSystem`、霊核、種族シナジー、防壁処理を使う。
5. 魔神化は味方モンスターに適用しない。

## 非対象

- 味方モンスターの魔神化。
- 味方モンスターのMP、スキルコスト、スキルAI。
- 味方モンスターごとの状態異常ターン処理。
- 味方モンスターがアイテムや魔神技を使う機能。

## ターン仕様

`TurnOrderActor.side` を以下に拡張する。

| side | 説明 |
|---|---|
| `PLAYER` | 主人公 |
| `ALLY` | 味方モンスター |
| `ENEMY` | 敵 |

AV初期値:

- 主人公: 0
- 味方モンスター: `10000 / spd`
- 敵: `10000 / spd`

主人公・味方モンスター・敵を同じAVキューに入れ、次の味方側 actor が来るまで敵を処理する。
味方側 actor が主人公なら `playerTurn`、味方モンスターなら `monsterTurn` に遷移する。

## 味方モンスター命令仕様

味方モンスター手番では以下を表示する。

- 現在手番のモンスター名
- 攻撃ボタン
- 対象は既存のターゲット選択を使う

攻撃処理:

1. `calculateMonsterAttackProfile(monster, { awakened: player.isAwakened })` で攻撃プロフィールを作る。
2. 現在ターゲットにダメージ計算する。
3. 防壁、弱点、耐性、会心、霊核表示を既存処理と同じように反映する。
4. 行動後、その味方モンスターのAVを `currentAv + actionDelay` に更新する。
5. 次の味方側 actor まで敵ターンを進める。

## UI仕様

- `BattlePhase` に `monsterTurn` を追加する。
- ターン順序UIでは `ALLY` を青緑系、`PLAYER` を紫、`ENEMY` を赤で表示する。
- パーティステータスでは現在手番の味方モンスターを active 表示にする。
- コマンドパネルは味方モンスター手番では「命令」「攻撃」だけを表示する。
- 魔神化ボタン、道具、主人公スキルは味方モンスター手番では表示しない。
- Auto中は味方モンスター手番でも自動攻撃する。

## BattleEngine仕様

純粋ロジックでは以下を変更する。

- `simulateAction` から自動 `processMonsterActions` を削除する。
- `simulateMonsterAction(monsterId, target, enemyCandidates?)` を追加する。
- 味方モンスターが生存していない、または存在しない場合はログを返さない。
- 味方モンスター攻撃ログは従来と同じ `MONSTER_ATTACK` を使うが、文言は「命令攻撃」にする。

## テスト方針

- `simulateAction` で主人公攻撃後に `MONSTER_ATTACK` が出ないことを確認する。
- `simulateMonsterAction` で指定モンスターだけが攻撃することを確認する。
- 霊核倍率が味方モンスターターン攻撃に反映されることを確認する。
- `TurnOrderSystem` で `ALLY` actor がプレビューに入り、敵処理が次の味方側 actor で止まることを確認する。
- 全Jest、型チェック、production build を通す。
