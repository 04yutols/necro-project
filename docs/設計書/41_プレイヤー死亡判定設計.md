# 41. プレイヤー死亡判定システム設計

> 作成日: 2026-05-24  
> 対象バグ: TECH_DEBT NC-1  
> 担当ファイル: `src/components/battle/BattleCanvas.tsx`, `src/logic/PlayerDefeat.ts`, `src/components/battle/ResultScreen.tsx`

---

## 1. 問題の概要

### 実装前の状態

`BattleCanvas.tsx` は敵の攻撃ダメージを浮かびテキストとログに表示するが、**どこにも HP を実際に減らす処理がない**。

```
現状:
  敵攻撃 → dmg 計算 → spawnFloat() → addLog() → (終わり)
  playerHp: 状態変数が存在せず、PartyStatusBar は常に maxHp を表示
```

その結果:
- HP バーが常にフル（フルHP でゲーム進行する）
- `playerHp <= 0` チェックがないのでゲームオーバーにならない
- バトルが永遠に続く

---

## 2. 設計方針

### 2.1 責任分担

| 責務 | 場所 |
|---|---|
| HP 減算・死亡判定の純粋ロジック | `src/logic/PlayerDefeat.ts` |
| バトル中の HP 状態管理 | `BattleCanvas.tsx` のローカル state + ref |
| 敗北演出・ResultScreen 遷移 | `BattleCanvas.tsx` `triggerPlayerDefeat()` |
| 敗北時 ResultScreen 表示 | `ResultScreen.tsx` `!isVictory` 分岐 |

### 2.2 状態モデル

```
playerMaxHp   = playerStats.hp （バトル開始時に固定、変化しない）
playerHp      = useState<number>（現在HP、敵攻撃・状態異常で減算）
playerHpRef   = useRef<number>  （setTimeout 内でも最新 HP を参照するための ref）
```

`playerHp` が変化 → `useEffect` で `playerHpRef.current` を同期。  
タイマーコールバック内では必ず `playerHpRef.current` を読む。

### 2.3 死亡検知のタイミング

| 発火元 | 処理 |
|---|---|
| `runEnemyTurn()` — 各敵の攻撃後 | `applyPlayerDamage → isPlayerDead` チェック |
| `resolvePlayerStatusBeforeAction()` — 毒/炎ティック | 同上 |

死亡検知時:
1. `enemyTurnSerialRef.current += 1` → 以降の setTimeout コールバックを無効化
2. `addLog('☠ 骸骨騎士は倒れた...')` でログ表示
3. 800ms 後に `setShowResult(true)` でリザルト画面へ遷移

---

## 3. `PlayerDefeat.ts` 仕様

```typescript
// HP 減算。最小 0 で止める。
function applyPlayerDamage(currentHp: number, damage: number): number

// 死亡判定。
function isPlayerDead(currentHp: number): boolean
```

- `applyPlayerDamage(800, 200)` → `600`
- `applyPlayerDamage(200, 500)` → `0` (over-kill でも負値にならない)
- `isPlayerDead(0)` → `true`
- `isPlayerDead(1)` → `false`

---

## 4. BattleCanvas 変更仕様

### 4.1 追加 state / ref

```typescript
const playerMaxHp = playerStats?.hp ?? 820;
const [playerHp, setPlayerHp] = useState(playerMaxHp);
const playerHpRef = useRef(playerMaxHp);
useEffect(() => { playerHpRef.current = playerHp; }, [playerHp]);
```

### 4.2 `battleParty` 構築の変更

```typescript
// Before:
hp: playerStats?.hp ?? 820, maxHp: (playerStats as any)?.maxHp ?? playerStats?.hp ?? 820,

// After:
hp: playerHp, maxHp: playerMaxHp,
```

### 4.3 `runEnemyTurn()` — 敵攻撃後に HP 減算

```typescript
const dmg = Math.round(...);
const newHp = applyPlayerDamage(playerHpRef.current, dmg);
playerHpRef.current = newHp;
setPlayerHp(newHp);

spawnFloat(...);
addLog(...);

if (isPlayerDead(newHp)) {
  triggerPlayerDefeat();
  return;  // forEach の残りの敵攻撃は triggerPlayerDefeat() 内のシリアル++で無効化
}
```

注意: `scheduledEnemies.forEach` の各コールバックは独立した setTimeout なので、最初の死亡検知後に `enemyTurnSerialRef.current` が増分され、後続コールバックは `turnToken !== enemyTurnSerialRef.current` で早期リターンする。

### 4.4 `resolvePlayerStatusBeforeAction()` — 状態異常ダメージ後に HP 減算

```typescript
if (result.totalDamage > 0) {
  const newHp = applyPlayerDamage(playerHpRef.current, result.totalDamage);
  playerHpRef.current = newHp;
  setPlayerHp(newHp);
  spawnFloat(...);
  addLog(...);
  if (isPlayerDead(newHp)) {
    window.setTimeout(() => triggerPlayerDefeat(), 300);
    return true;  // 行動スキップ + 敗北へ
  }
}
```

### 4.5 `triggerPlayerDefeat()` 関数（新規）

```typescript
function triggerPlayerDefeat() {
  enemyTurnSerialRef.current += 1;  // 進行中の敵アクションをキャンセル
  setAuto(false);
  setPhase('waveTransition');        // プレイヤー入力を無効化
  addLog('☠ 骸骨騎士は倒れた... バトル終了。');
  setBattleResult({
    isVictory: false,
    expGained: 0,
    goldGained: 0,
    itemsGained: [],
    monstersGained: [],
    isPurplePillar: false,
    wavesCleared: waveIndexRef.current,
    totalWaves: battleWaves.length,
    clearTime: Math.round((Date.now() - battleStartedAtRef.current) / 1000),
  });
  window.setTimeout(() => setShowResult(true), 800);
}
```

### 4.6 バトルリセット (`useEffect([battleWaves])`)

```typescript
playerHpRef.current = playerMaxHp;
setPlayerHp(playerMaxHp);
```

## 5. ResultScreen 変更仕様

敗北時（`!isVictory`）に以下を変更:

| 要素 | 変更 |
|---|---|
| ランクバッジ | 金円を赤骸骨アイコンに変更 |
| EXPERIENCE セクション | 非表示 |
| BATTLE REWARDS セクション | 「報酬なし（敗北）」に差し替え |
| 「鑑定へ進む」ボタン | 「マップへ撤退」ボタン（`onFinish()` 直呼び）に差し替え |
| 鑑定画面への遷移 | 発生しない（`goToAppraisal` 非呼び出し） |

## 6. テスト仕様 (`PlayerDefeat.test.ts`)

| テストケース | 検証内容 |
|---|---|
| 通常ダメージ | `applyPlayerDamage(800, 200)` → `600` |
| 致死ダメージ（ちょうど）| `applyPlayerDamage(200, 200)` → `0` |
| 過剰ダメージ（負値にならない） | `applyPlayerDamage(100, 9999)` → `0` |
| ゼロダメージ | `applyPlayerDamage(500, 0)` → `500` |
| 連続ダメージの累積 | 300 → 250 → 0 の追跡 |
| 死亡判定: HP > 0 | `isPlayerDead(1)` → `false` |
| 死亡判定: HP === 0 | `isPlayerDead(0)` → `true` |
| 死亡判定: ダメージ後 | `isPlayerDead(applyPlayerDamage(100, 100))` → `true` |
| 瀕死でも生存 | `isPlayerDead(applyPlayerDamage(100, 99))` → `false` |
