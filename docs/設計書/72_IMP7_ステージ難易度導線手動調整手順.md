# 72 — ステージ進行・難易度導線 手動調整手順

> 対象: `src/data/master/stages.json` / `src/data/master/enemies.json` / `scripts/progression-report.mjs`  
> 作成日: 2026-05-30  
> 関連: `75_マスターデータ制作運用手順.md`

---

## 1. 目的

今後ステージを追加していくと、意図せず「前のノードから急に勝てない」「次のボスが前ステージより弱い」「報酬だけ先に強すぎる」といったズレが生まれる。本書は、ステージ間の実効耐久・脅威度・推奨導線を見ながら、敵配置や報酬を調整するための補助手順である。

---

## 2. 編集するファイル

### 2.1 ステージ導線

`src/data/master/stages.json`

追加・調整候補:

```json
"recommendedLevel": 5,
"recommendedWeapon": "SR",
"rewards": {
  "baseExp": 220,
  "baseGold": 180,
  "dropTable": []
}
```

`recommendedLevel` / `recommendedWeapon` は現時点ではレポート上の導線チェック用で、UIに表示する場合は `AreaMap.tsx` 側へ接続する。

### 2.2 敵ステータス

`src/data/master/enemies.json`

急な崖を緩和する場合は、次の順で触る。

1. 前ステージの報酬を増やす。
2. 次ステージの WAVE1 / WAVE2 を少しだけ弱める。
3. ボスだけが弱い場合は `71_IMP3_敵ボスバランス手動調整手順.md` に従う。

---

## 3. レポートスクリプト

### 3.1 警告がある遷移だけ表示

```bash
npm run balance:progression
```

### 3.2 全ステージ遷移を表示

```bash
npm run balance:progression -- --all
```

### 3.3 特定ステージの前後だけ確認

```bash
npm run balance:progression -- --stage=area1_node2 --all
```

### 3.4 CI向け

```bash
npm run balance:progression -- --strict
```

`FAIL` がある場合に exit code `2` で終了する。現時点では手動運用を推奨する。

---

## 4. レポート指標

| 指標 | 意味 | 警告目安 |
|---|---|---|
| `EHP` | ステージ全体の実効耐久合計 | 前ステージ比 2.5x 以上で WARN、4.0x 以上で FAIL |
| `peakTHR` | もっとも危険な WAVE の脅威度 | 前ステージ比 2.0x 以上で WARN、4.0x 以上で FAIL |
| `recommendedLevel` | プレイヤーへの推奨レベル案内 | 急上昇ステージで未設定なら WARN |
| `recommendedWeapon` | 推奨武器レアリティ | 急上昇ステージで未設定なら WARN |

`THR` は `ATK × SPD × 会心補正` の簡易値で、厳密なダメージ期待値ではなく「危険度の相対比較」として使う。

---

## 5. 調整手順

1. `npm run balance:progression -- --all` で全ステージ遷移を見る。
2. `FAIL` が出た遷移を優先する。
3. `EHP` が跳ねている場合は敵HP・防壁・復活・召喚を確認する。
4. `peakTHR` が跳ねている場合は敵ATK・SPD・会心率を確認する。
5. あえて崖を残すなら `recommendedLevel` / `recommendedWeapon` を追加する。
6. 初回クリア報酬で補助する場合は前ステージの `rewards.dropTable` を調整する。
7. 変更後に `npm run balance:progression -- --stage=<stageId> --all` を再実行する。

---

## 6. 現状の代表例

`area1_node1 -> area1_node2` は、総EHPと最大WAVE脅威度が大きく跳ねるため、以下のいずれかが候補になる。

- `area1_node2` に `recommendedLevel: 5` / `recommendedWeapon: "SR"` を設定する。
- `area1_node1` の確定報酬を少し厚くし、SR武器か残滓強化の導線を作る。
- `area1_node2` の WAVE1 を少し弱めて、突入直後の即死感を減らす。

---

## 7. 推奨確認コマンド

```bash
npm run balance:progression -- --stage=area1_node2 --all
npm run balance:report -- --stage=area1_node2 --all
npm test -- --runInBand src/logic/DungeonSystem.test.ts
```

ステージ構成と敵ステータスを同時に触った場合は、ボス逆転レポートも併用する。
