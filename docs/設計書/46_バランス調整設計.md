# 46. ゲームバランス調整設計（王道 JRPG スケール）

> 作成日: 2026-05-24（改訂版）
> 対象問題: プレイヤー ATK 過剰 / 武器 ATK 過剰 / 敵 HP 不足
> 担当ファイル: `src/app/actions.ts`, `src/logic/WeaponSystem.ts`,
>               `src/data/master/items.json`, `src/data/master/monsters.json`,
>               `src/data/master/stages.json`

---

## 1. 問題の概要

### 根本原因

| 問題 | 現在値 | 症状 |
|---|---|---|
| スタート武器 `ilv=40` | bone_cleaver weapon ATK=**307** | 武器だけで ATK+307 |
| 武器式の下限が 58% | `ilvScale = 0.58 + (ilv/90) * 0.42` | ilv=1 でも ATK=235 |
| プレイヤー基礎 ATK 120（戦士補正後 144） | 合計 **ATK=451** | 全敵を 1 ターンで溶かす |
| 敵 HP が 50〜300 | goblin HP=50 | 451 ダメージで **440** → 即死 |

プレイヤーが **ゲームプレイとして機能しない水準** のパワーを持っている。

---

## 2. 設計方針：王道 JRPG バランス

ドラクエ・FF 序盤をベースとした直感的な小数値スケール。

### 体感目標（area1_node1「王都外縁の墓道」）

| 場面 | 体感目標 |
|---|---|
| プレイヤーの通常攻撃 | 雑魚を **2 撃**で倒す |
| プレイヤーのスキル | 雑魚を **1 撃**で倒せる |
| 雑魚のプレイヤーへの攻撃 | **1〜3 ダメージ**（死ぬ気がしない） |
| WAVE 2（シールド敵） | 通常攻撃 2 撃でシールド破壊 |
| WAVE 3（強めの雑魚） | 通常攻撃 4 撃 / スキル 3 撃で撃破 |
| WAVE 3 の攻撃 | **4〜5 ダメージ**（若干の緊張感） |
| area1_node1 最終 WAVE | **ボスなし**。強い雑魚止まり |

> ボス戦は area1_node3 以降に設計する。area1_node1 はチュートリアル完結ステージ。

### 3-2. 武器 ATK スケール全面改訂（`src/logic/WeaponSystem.ts`）

#### ① lv90 ベース ATK テーブル

大きな数値は endgame まで使わない。JRPG スケールで設計し直す。

```typescript
// Before
export const WEAPON_LV90_BASE_ATK: Record<WeaponRarity, Record<WeaponArchetype, number | null>> = {
  R:   { LOW: 354, MID: 401, HIGH: 448, MYTHIC: null },
  SR:  { LOW: 454, MID: 510, HIGH: 565, MYTHIC: null },
  SSR: { LOW: 542, MID: 608, HIGH: 674, MYTHIC: null },
  UR:  { LOW: null, MID: null, HIGH: null, MYTHIC: 780 },
};

// After
export const WEAPON_LV90_BASE_ATK: Record<WeaponRarity, Record<WeaponArchetype, number | null>> = {
  R:   { LOW: 45, MID: 60,  HIGH: 75,  MYTHIC: null },
  SR:  { LOW: 58, MID: 78,  HIGH: 97,  MYTHIC: null },
  SSR: { LOW: 68, MID: 92,  HIGH: 115, MYTHIC: null },
  UR:  { LOW: null, MID: null, HIGH: null, MYTHIC: 130 },
};
```

#### ② ilvScale 計算式（下限を撤廃）

```typescript
// Before（下限 58%）
const ilvScale = 0.58 + (ilv / WEAPON_MAX_ILV) * 0.42;

// After（ゼロから線形）
const ilvScale = ilv / WEAPON_MAX_ILV;
```

この 2 つの変更により、武器 ATK の成長曲線は以下になる：

| ilv | R MID | SR MID | SSR MID | UR MYTHIC | 備考 |
|---|---|---|---|---|---|
| **1**（初期装備） | **1** | **1** | **1** | **1** | チュートリアル開始 |
| 10 | 7 | 9 | 10 | 14 | 序盤武器強化後 |
| 20 | 13 | 17 | 20 | 29 | |
| **40**（旧初期） | **27** | **35** | **41** | **58** | 第1章中盤 |
| 60 | 40 | 52 | 61 | 87 | 第1章終盤 |
| 80 | 53 | 69 | 82 | 116 | |
| **90**（最大） | **60** | **78** | **92** | **130** | 第1章クリア後想定 |

## 4. ダメージシミュレーション

**戦士 Lv1 合計 ATK = 11、HP = 68、DEF = 12**

### WAVE 1 — grave_soldier（DEF=3, HP=15）

| アクション | 計算 | ダメージ | 撃破 |
|---|---|---|---|
| 通常攻撃（×1.0） | 11 × 0.985 | **10** | **2 撃** |
| スキル（×1.5） | 16.5 × 0.985 | **16** | **1 撃** |

敵 → プレイヤー（ATK=3, player DEF=12）：

```
3 × (1 - 12 / 212) = 3 × 0.943 = 2.83 → floor → 2 ダメージ
プレイヤー HP 68 → 34 撃耐久（安全）
```

### WAVE 1 — rot_hound（DEF=2, HP=12, SPD=110 で先行）

| アクション | ダメージ | 撃破 |
|---|---|---|
| 通常攻撃 | **10** | **2 撃** |
| スキル | **16** | **1 撃** |

```
敵 ATK 4 → 3 ダメージ（SPD 110 で先行、プレイヤーが 23 撃耐久）
```

### WAVE 2 — abyss_warden（DEF=6, shieldHp=20, HP=35）

| フェーズ | アクション | ダメージ | 撃破 |
|---|---|---|---|
| シールド（HP=20） | 通常攻撃 | **10** | **2 撃で破壊** |
| シールド（HP=20） | 弱点スキル（LIGHT / FIRE） | 10 × 1.3 = **13** | **2 撃または 1 撃** |
| 本体（HP=35） | 通常攻撃 | **10** | **4 撃** |

```
敵 ATK 5 → 4 ダメージ（プレイヤー 17 撃耐久）
→ シールド破壊から本体討伐まで戦闘が成立する
```

### WAVE 3 — grave_soldier（DEF=3, HP=15）+ grave_knight（DEF=8, HP=40）

**grave_soldier（残り HP 15）:**
```
通常攻撃 10 → 2 撃撃破（先に処理してOK）
```

**grave_knight:**

| アクション | ダメージ | 撃破 |
|---|---|---|
| 通常攻撃 | **10** | **4 撃** |
| スキル（×1.5） | **15** | **3 撃** |

```
敵 ATK 6 → 5 ダメージ（プレイヤー 14 撃耐久）
2 体同時対処でスキルと行動優先度の判断が生まれる
```
