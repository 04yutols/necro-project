# 77 — IMP-5 職業別通常攻撃種別設計

> 対象: `src/data/master/jobs.json` / `src/types/game.ts` / `src/logic/JobSystem.ts` / `src/logic/BattleEngine.ts` / `src/components/battle/BattleCanvas.tsx`  
> 対応日: 2026-05-30  
> 関連: `docs/progress/IMPROVEMENTS.md` の `IMP-5`

---

## 1. 背景

通常攻撃は全職業で使用できる、SPコスト0の基本行動である。旧実装では `BattleEngine` と `BattleCanvas` の両方が通常攻撃の `attackType` を `SLASH` に固定していた。

```typescript
attackType = 'SLASH';
```

このため、魔法使いでも斬撃VFXが出る、盗賊の通常攻撃が急所突き系の衝撃表現にならない、といった職業表現の不一致が起きていた。

---

## 2. 問題

`attackType` は単なる表示ラベルではなく、複数の戦闘処理に流れる。

| 接続先 | 影響 |
|---|---|
| `BattleLog.attackType` | ログを利用する演出・同期層 |
| `BattleCanvas.triggerSkillEffect()` | 通常攻撃VFX |
| `StatusAilmentSystem.inferAilmentForAction()` | 暗黙の状態異常候補 |
| `DemonizationSystem.getDemonActionHitCount()` | 魔神化中の連撃数 |
| `DemonizationSystem.getDemonDamageMultiplier()` | 魔法系攻撃の倍率分岐 |
| `BattleCanvas.applyDemonRiskFeedback()` | 魔神化リスク表示 |

全職業を `SLASH` として扱うと、職業マスターが持つ攻撃スタイルと、実際のバトルログ・VFX・状態異常判定が一致しない。

---

## 3. 採用仕様

### 3.1 JobData

`JobData` に任意フィールド `baseAttackType?: SkillAttackType` を追加する。

```typescript
interface JobData {
  baseAttackType?: SkillAttackType;
}
```

任意フィールドにする理由は、古いデータやテスト用の最小モックとの互換性を保つためである。未設定時は従来挙動の `SLASH` にフォールバックする。

### 3.2 全12職の割り当て

| jobId | 通常攻撃種別 | 根拠 |
|---|---|---|
| `warrior` | `SLASH` | 剣士。既存の剣技がすべて斬撃 |
| `mage` | `MAGIC` | 五属性の術式を扱う魔法職 |
| `dark_priest` | `MAGIC` | 闇魔法・呪詛・吸収を扱う術師 |
| `rogue` | `STRIKE` | 急所突きを基準にした技巧職 |
| `dark_knight` | `SLASH` | 闇をまとった魔剣による斬撃職 |
| `berserker` | `SLASH` | 血炎断ちを主軸にした高火力斬撃職 |
| `archmage` | `MAGIC` | 大規模術式を主軸にした上位魔法職 |
| `sorcerer` | `PROJECTILE` | 高速詠唱で風槍などを射出する職 |
| `warlock` | `MAGIC` | 奈落呪を主軸にした呪詛魔法職 |
| `necromancer` | `SUMMON` | 死霊軍団を介入させる召喚職 |
| `assassin` | `SLASH` | 背後から急所を斬る処刑職 |
| `trickster` | `PROJECTILE` | 幻雷弾など虚像から弾を放つ攪乱職 |

通常攻撃はダメージ行動なので、`HEAL` は割り当てない。

### 3.3 共通解決関数

`JobSystem` にフォールバックを集約する。

```typescript
export function getBaseAttackType(
  job: Pick<JobData, 'baseAttackType'> | null | undefined,
): SkillAttackType {
  return job?.baseAttackType ?? 'SLASH';
}
```

これにより、`BattleEngine` と `BattleCanvas` が同じルールで通常攻撃種別を決める。

---

## 4. 実装詳細

### 4.1 BattleEngine

`processPlayerAction()` で取得済みの `currentJob` から通常攻撃種別を解決する。

```typescript
const currentJob = this.masterData.getJob(player.currentJobId);
const baseAttackType = getBaseAttackType(currentJob);

if (actionType === 'PHYSICAL_ATTACK') {
  energyCost = 0;
  attackType = baseAttackType;
}
```

既存のアクション識別子 `PHYSICAL_ATTACK` は変更しない。この値は「通常攻撃コマンド」を表す既存名であり、ダメージ計算式は現在 `ATK / DEF` に統一されている。今回変更するのは演出軸である `attackType` のみ。

### 4.2 BattleCanvas

現在職業から `baseAttackType` を解決し、`handleAttack()` 内の固定 `SLASH` を置き換える。

置き換え対象:

- 魔神化中のヒット数計算
- `triggerSkillEffect()` の通常攻撃VFX
- `calculatePlayerHitDamage()` の攻撃種別
- `applyAilmentToEnemy()` の状態異常推論
- `applyDemonRiskFeedback()` のリスク表示

通常時の無属性 `element: "NONE"` と、通常攻撃後のSP回収量は変更しない。
