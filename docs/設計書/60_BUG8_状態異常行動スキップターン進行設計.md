# BUG-8 状態異常行動スキップ時のターン進行設計

> 作成日: 2026-05-26
> 対象: `src/logic/BattleEngine.ts`, `src/logic/BattleEngine.test.ts`

## 1. 背景

`FREEZE` / `PARALYSIS` は `processStatusEffects()` で `skipAction` を返し、対象の行動不能を表現する。

既存の `BattleEngine.simulateAction()` はプレイヤーに `skipAction` が立った時点で即 `return` していた。

```ts
if (playerStatus.skipAction) {
  this.addLog('STATUS_SKIP', player.name, player.name, `${player.name}は状態異常で行動できない。`);
  this.updateState();
  return this.logs;
}
```

このため、プレイヤーが麻痺や凍結で行動できないターンでは、敵の反撃フェーズまで止まっていた。

## 2. 問題

行動不能は「対象のアクションを失わせる効果」であり、バトル全体の時間停止ではない。

既存挙動では以下の問題が起きる。

- 麻痺したプレイヤーが敵の攻撃を受けず、安全な1ターンになってしまう。
- 敵反撃・敗北判定・ターン進行が状態異常によって短絡される。
- `FREEZE` / `PARALYSIS` が防御的に強すぎる挙動になり、状態異常設計の緊張感と矛盾する。

## 3. 設計方針

### 3.1 スキップの対象

プレイヤーに `skipAction` が立った場合、止める範囲を以下に限定する。

| フェーズ | skipAction時の扱い |
|---|---|
| ターン開始ギミック | 実行済み |
| 状態異常tick / duration減少 | 実行済み |
| プレイヤー行動 | スキップ |
| SP回復 / スキル消費 / 魔神化ゲージ加算 | 発生しない |
| プレイヤー攻撃に紐づく軍団追撃 | 発生しない |
| 敵の反撃 | 発生する |
| 敗北判定 | 敵反撃後に実行 |
| ターン更新 | 生存していれば実行 |

### 3.2 軍団追撃の扱い

軍団追撃は `processMonsterActions()` による「プレイヤー行動後の追撃」として扱う。そのため、プレイヤーが行動不能のターンは追撃も発生しない。

これにより、麻痺は以下のような明確なリスクになる。

1. 状態異常で主人公が行動できない。
2. 追撃も出ない。
3. 敵だけが攻撃する。

### 3.3 実装方針

`simulateAction()` 内で `playerActionSkipped` フラグを持つ。

```ts
let playerActionSkipped = false;

if (playerStatus.skipAction) {
  playerActionSkipped = true;
  this.addLog('STATUS_SKIP', ...);
}

if (!playerActionSkipped) {
  this.processPlayerAction(...);
  this.processMonsterActions(...);
}

this.processEnemyCounterAttack(target);
```

早期returnは、プレイヤーが状態異常DoTや敵反撃で倒れた場合のみに限定する。

## 4. テスト方針

`src/logic/BattleEngine.test.ts` に麻痺による行動スキップの回帰テストを追加する。

| テスト | 確認内容 |
|---|---|
| 麻痺スキップ | `PARALYSIS` のskip時に `STATUS_SKIP` が出る |
| プレイヤー行動抑止 | `PHYSICAL_ATTACK` が出ず、SPも増えない |
| 追撃抑止 | `MONSTER_ATTACK` が出ない |
| 敵反撃継続 | `ENEMY_ATTACK` が出てプレイヤーHPが減る |
| duration更新 | 麻痺の残りターンが減る |

## 5. 完了条件

- `skipAction` がプレイヤー行動だけを止め、敵反撃を止めない。
- 麻痺ターンが安全ターンにならない。
- BattleEngine単体テスト、全Jest、型検査、ビルドが成功する。
