> 最終更新: 2026-07-11 ｜ 生成方法: コードからのリバースエンジニアリング（コードが正） ｜ 主要ソース: `src/app/page.tsx`, `src/app/layout.tsx`, `src/app/globals.css`, `tailwind.config.ts`, `src/lib/motion.ts`, `src/components/layout/`, `src/components/home/HomeHero.tsx`, `src/components/map/AreaMap.tsx`, `src/components/battle/BattleCanvas.tsx`, `src/components/battle/ResultScreen.tsx`, `src/components/legion/LegionHub.tsx`, `src/components/job/JobChangeScreen.tsx`, `src/components/necro/NecroLab.tsx`, `src/components/yomi/YomiTowerScreen.tsx`, `src/components/story/`, `src/components/tutorial/`, `src/components/auth/`, `src/logic/JobSystem.ts`, `src/logic/ResidueScore.ts`

## 2. 画面遷移とフルスクリーンルール（`src/app/page.tsx`）

```
isInBattle == true       → BattleCanvas を position:absolute inset:0 zIndex:9999 で全画面（背景 #000）
currentTab == 'MAP'      → AreaMap を position:absolute inset:0 zIndex:9999 で全画面
それ以外                  → ResponsiveFrame の mainMonitor に renderMainContent()（AnimatePresence mode="wait"）
```

- 出撃フロー: `requestStageStart(stageId)` → 非ゲストは Server Action `startStageAction` で `stageAttemptId` を取得（失敗時は SYNC ERROR トースト、z:10020、`bottom: calc(env(safe-area-inset-bottom) + 18px)`）→ `triggerStageEnter(stageId)` がストーリーを差し込む場合は pending 保留 → `startStageNow` で `isInBattle=true` + `currentTab='BATTLE'`。取得中は `LoadingScreen`（「Preparing Invasion / 侵攻証跡を発行しています」）。
- 戦闘終了 `finishBattle`: クリア後チュートリアルフェーズあり → `HOME` / `isYomiStage(activeStageId)` → `YOMI` / それ以外 → `MAP` に復帰。
- `ShardEquipModal`（魂の欠片装備）は `equippingMonsterId != null` のとき page.tsx 直下にマウント（`fixed inset-0 z-[100]`、パネルは `z-[101]`、`useFocusTrap` 使用）。
- MAP のみタブアニメーションでなく `fullscreenScreenVariants`（scale+blur フェード）を使用。

## 3. レイアウトシェルとセーフエリア

### 3-1. ResponsiveFrame（`src/components/layout/ResponsiveFrame.tsx`）

現行の唯一のアプリシェル。`position:fixed inset:0` + `flex-col` + `overflow:hidden`、背景 `#050505`。構成は「`<main>`（flex:1, min-h-0, overflow:hidden, z:10）+ `BottomNavBar`（`isFullscreen` でない場合）」の 2 段のみ。props の `leftSidebar` / `rightSidebar` は受け取るが**現在は空 div が渡されており未使用**。背景に `pixel-grid`（横1pxライン）を 20% opacity で敷く。

### 3-2. セーフエリア規約

- ルート: `layout.tsx` の viewport で `viewportFit: 'cover'`, `userScalable: false`, `maximumScale: 1`。
- 高さは `100dvh` を使用（page.tsx `h-[100dvh]`、`.ios-app-shell` は `min-height:100vh` + `100dvh` の二段構え）。
- 上端: 各画面ヘッダが `padding-top: max(12px, env(safe-area-inset-top, 12px))`（BattleCanvas / JobChangeScreen / AreaMap）または `calc(env(safe-area-inset-top) + 18px)`（HomeHero）。
- 下端: BottomNavBar と BattleCanvas SystemBar が `env(safe-area-inset-bottom)` を反映。
- スクロール領域は `.safe-scroll`（`-webkit-overflow-scrolling: touch; overscroll-behavior: contain`）+ `flex-1 min-h-0 overflow-y-auto` パターン。`html`/`body` は `overflow:hidden` + `overscroll-behavior:none`。

## 7. Framer Motion 規約（`src/lib/motion.ts`）

```typescript
export const MOTION = {
  spring: {
    standard: { type: 'spring', stiffness: 295, damping: 33 },
    soft:     { type: 'spring', stiffness: 260, damping: 28 },
    snappy:   { type: 'spring', stiffness: 330, damping: 34 },
  },
  duration: { fast: 0.16, normal: 0.22, slow: 0.38 },
} as const;
```

- **タブ切替**: `tabScreenVariants` — enter/exit で `x: ±28px` + `blur(8px)` + opacity。方向は `getNavigationDirection(prev, current, APP_TAB_ORDER)`（インデックス比較で -1/0/+1）。page.tsx が `AnimatePresence mode="wait"` + `custom={direction}` + `transition: MOTION.spring.standard` で適用。
- **フルスクリーン遷移（MAP）**: `fullscreenScreenVariants` — enter `scale:0.985 blur(6px)` / exit `scale:1.01 blur(6px)`、`duration: MOTION.duration.normal, ease: 'easeOut'`。
- **リスト入場スタッガー**: `{ ...MOTION.spring.standard, delay: index * 0.1 }`（HomeHero）、`{ ...MOTION.spring.soft, delay: min(floor * 0.018, 0.3) }`（YomiTowerScreen）。
- タップフィードバックは `whileTap={{ scale: 0.9〜0.96 }}` を各所で使用。テストは `src/lib/motion.test.ts`。

## 8. iOS Safari レイアウト規則

**最重要規則: `overflow: hidden` と CSS `transform`（Framer Motion の残留 translate 含む）を同一要素に置かない。**

```tsx
// GOOD — 2層分離（page.tsx, JobChangeScreen, LegionHub 等が全面採用）
<motion.div animate={{ y: 0 }} style={{ position: 'absolute', inset: 0 }}>
  <div className="absolute inset-0 overflow-hidden flex flex-col">
    {/* content */}
  </div>
</motion.div>
```

理由: Framer Motion はアニメ完了後も `transform: translateY(0px)` を残すため、iOS Safari では同一要素の `overflow:hidden` クリッピングが破綻する。

付随規約（コードで確認できる実装慣習）:
- 高さは `100dvh`（`h-[100dvh]`）。`100vh` 単独は使わない（`.ios-app-shell` は `min-height:100vh` → `100dvh` の上書きフォールバック）。
- 縦構成は `shrink-0`（ヘッダ/フッタ）+ `flex-1 min-h-0 overflow-y-auto .safe-scroll`（本文）。
- `env(safe-area-inset-*)` を上下端 padding に反映（§3-2）。
- タップ領域は最小 38px（バトル SystemBar）〜44px 以上（`min-h-11` = 44px、挑戦・戻る等の主要ボタン）。
- `button` は `-webkit-tap-highlight-color: transparent` + `touch-action: manipulation`（globals.css グローバル指定）。
- 横スクロール UI は `overscroll-behavior-x: contain` + スクロールバー非表示（`.job-rail-scroll`）。
- Vite dev 用に `#root` にも `width/height:100%` を指定（`#__next, #root, main` セレクタ）。
