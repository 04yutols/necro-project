### 1.1 世界観と主人公アルドの目的

ストーリー登場人物はマスターデータ `src/data/story/characters.json` に定義された4名のみ。

| ID | 名前 | 役どころ（シーンデータより） |
|---|---|---|
| `aldo` | アルド | 主人公。魔族の少年 |
| `line` | ライン | アルドの親友。勇者の末裔 |
| `demon_king` | 魔王 | ラインを殺し、王国を滅ぼした存在 |
| `narrator` | （地の文） | ナレーション |

プロローグ（`src/data/story/ch1_scenes.json` PROLOGUE_00〜03）で確定している物語:

- 魔族の少年アルドには、種族を超えた親友＝勇者の末裔ラインがいた。
- ラインは「現代の魔王」に殺され、死の間際にアルドへ「勇者の力」を託す（「俺の……力を……使ってくれ……」）。
- アルドは「絶対に……終わらせてやる」と誓い、魔王への復讐の旅に出る。

第1章の舞台は「魔王に滅ぼされた王国」の王都であり、シーン本文にも「魔王に滅ぼされた王国の外縁へ踏み込んだアルドは、かつての友が愛した世界の残骸を見た」とある（`ch1_scenes.json`）。

> 補足: 旧GDD（`docs/requirements.md` GDD-001）にはもう一つの目的「自身が新魔王になる」と第二部構想（天界・他の魔王候補との戦い）が記されているが、実装済みシーンデータ（第1章19シーン）には「新魔王になる」目的を明示する台詞は確認できなかった。現時点でコードから確定するアルドの動機は「親友の復讐（魔王討伐）」である。

## 2. コアゲームループ

```
拠点（HOME タブ / HomeHero）
  └─ 編成（EQUIP=LegionHub）・転職（JOB）・残滓強化（LAB=NecroLab）
      ↓ 「出撃」
MAP（AreaMap ＝全画面オーバーレイ）
  └─ エリア選択 → ノード（ステージ）選択
      ↓ requestStageStart(stageId)
         ├─ ログイン時: startStageAction で stageAttemptId を発行（ゲストは省略）
         └─ STAGE_ENTER ストーリーシーンがあれば先に再生してから開戦
BATTLE（BattleCanvas ＝全画面オーバーレイ・ssr:false 動的ロード）
  └─ 3WAVE ターンバトル → リザルト（EXP / Gold / ドロップ）
      ↓ finishBattle()
戻り先の分岐:
  ├─ クリア後チュートリアルが控えている → HOME
  ├─ 黄泉ステージ（yomi_bNN）だった → YOMI タブ
  └─ それ以外 → MAP
```

根拠: `src/app/page.tsx:178-236`（`startStageNow` / `requestStageStart` / `finishBattle`）。戻り先分岐は `getTutorialPhaseAfterClear`（`src/data/tutorial/triggers.ts`）と `isYomiStage`（`src/logic/YomiFloors.ts`）による。

### 2.1 タブ構成

Zustand の `currentTab` が唯一のナビゲーション状態（URLルーティングなし）。型は 8 値:

```
'HOME' | 'BATTLE' | 'MAP' | 'EQUIP' | 'LAB' | 'YOMI' | 'LOGS' | 'JOB'
```

根拠: `src/store/useGameStore.ts:341`

| タブ | 画面 | ボトムナビ表示 | 備考 |
|---|---|---|---|
| HOME | `HomeHero` | ○（HOME） | 拠点。JOB への入口メニュー「転職・職業 / UMBRA RITE-HALL」あり（`HomeHero.tsx:129`） |
| MAP | `AreaMap` | ○（MAP） | 全画面オーバーレイ（`position:absolute; inset:0; zIndex:9999`） |
| BATTLE | `BattleCanvas` | ○（BATTLE） | 戦闘中のみ全画面。非戦闘時は「No Active Battle」表示 |
| EQUIP | `LegionHub` | ○（ラベルは LEGION） | 軍団編成 + 装備 |
| LAB | `NecroLab` | ○（LAB） | 深淵の残滓。**未解放時はロック画面**（§5） |
| YOMI | `YomiTowerScreen` | ○（YOMI） | 黄泉の階層。**未解放時はロック画面**（§5） |
| LOGS | 物語 / 戦歴 / 世界 の3パネル | ○（LOGS） | `StoryArchive` / `NecroLog` / `WorldLogPanel` |
| JOB | `JobChangeScreen` | ×（ナビ非表示） | HOME のメニューから遷移 |

ボトムナビは 7 タブ（JOB を除く）。根拠: `src/components/layout/BottomNavBar.tsx:9-16`

## 5. 解放ゲート一覧

すべて DB 保存の `player.clearedStages`（クリア済みステージID配列）ベースで判定する。クライアント専用フラグ（CH1_CLEARED 等）は解放判定に使わない。

| 機能 | 解放条件 | ロック時の挙動 | 根拠 |
|---|---|---|---|
| LAB タブ（深淵の残滓） | `clearedStages` に `area1_node3` | 「深淵の残滓」ロック画面（第2章到達後に解放の案内） | `src/logic/AbyssalResidueUnlockSystem.ts:3,8-10`, `src/app/page.tsx:347-354` |
| 残滓・素材のステージドロップ | 上記解放済み **かつ** `stage.chapter >= 2` | 未解放時は dropTable から `RESIDUE`/`MATERIAL` を除外 | `AbyssalResidueUnlockSystem.ts:12-28` |
| YOMI タブ（黄泉の階層） | `clearedStages` に `area1_node3` | 「黄泉の階層」ロック画面（亡国の王都制圧後に解放の案内） | `src/logic/YomiUnlockSystem.ts`, `src/app/page.tsx:360-367` |

| 第2章エリア（幽霊都市） | `area2_gate` の unlockRequires は `area1_node3` | エリア自体はマップ上で「未解放/前章の霧を晴らす」表示 | `stages.json area2_gate`, `AreaMap.tsx:504,596` |

- **オンライン**: 認証フロー（authRequired / characterRequired / guest / sessionExpired 等の状態分岐が `page.tsx` に実在）、世界ログパネル、ランキング。
- **管理画面**: `/admin` 配下にエネミー編集・監査・AIエージェント（`src/app/admin/`）。
